The differential pair: why analog designers love it

Analog & mixed-signal Intermediate 27 Nov 2026 5 min read By Ketuna

Two matched transistors and a tail current amplify the difference between two inputs and ignore what they share. Learn how the pair steers current, its gain, its common-mode rejection, and its role in op-amps.

In this article
  1. Two transistors sharing one current
  2. Differential gain
  3. Why common-mode signals are rejected
  4. Inside op-amps and comparators
  5. Try it yourself

Open the schematic of almost any op-amp, comparator or ADC front end and the first thing the input meets is a differential pair. Its job sounds simple: amplify the difference between two voltages and ignore whatever they have in common. That property, called common-mode rejection, is what lets a circuit pick a small signal out of supply noise, ground shifts and interference that hit both inputs equally. This article explains how the pair does it, with numbers.

Two transistors sharing one current

The pair is two matched NMOS transistors, M1 and M2, whose sources are joined and fed by a single tail current source ISS. Each drain has a load, here a resistor RD to VDD. The inputs go to the two gates.

The key constraint is that the two drain currents must always add up to ISS. The tail does not care how the current splits; it only fixes the total.

  • Equal inputs: by symmetry, each side carries ISS/2.
  • One input slightly higher: that transistor gets a bit more VGS and takes more current; the other must give up exactly the same amount. The shared source node moves to keep the sum constant.
  • Large difference: eventually one transistor takes all of ISS and the other turns off. For a square-law device this happens when the input difference reaches √2 times the balanced overdrive.

So the pair is a current steering circuit. A differential input voltage decides how a fixed current is shared, and the loads turn that sharing into output voltages.

Differential gain

For small input differences, write the inputs as a common part plus and minus half the difference: vin+ = vcm + vd/2 and vin− = vcm − vd/2. The joined sources sit at a point that does not move for a purely differential signal, because one side's current rises exactly as the other's falls. Each transistor therefore behaves like a common-source stage driven by vd/2.

The current change on each side is gmvd/2, and the voltage between the two outputs is:

Ad = vout / vd = gm RD (differential output)

Taking the output from one drain only gives half of that, gmRD/2.

Worked example, illustrative numbers: ISS = 100 µA, so 50 µA per side; VOV = 0.2 V; RD = 20 kΩ. Then gm = 2 × 50 µA / 0.2 V = 500 µS and the differential gain is 500 µS × 20 kΩ = 10. The pair switches fully at a difference of √2 × 0.2 V ≈ 0.28 V; beyond that it is a switch, not an amplifier.

Why common-mode signals are rejected

Now raise both inputs together by vcm. If the tail were an ideal current source, nothing could change: the total is fixed, the split is symmetric, so each side still carries ISS/2. Only the shared source node rises, following the inputs. The outputs do not move at all.

A real tail source has a finite output resistance Rtail. When the source node rises, a little extra current flows through Rtail, split equally between the two sides. Each output moves by roughly:

Acm ≈ RD / (2Rtail)

Continuing the example with Rtail = 200 kΩ: Acm = 20 kΩ / 400 kΩ = 0.05 at each output. Compare it with the single-ended differential gain from the same drain, gmRD/2 = 5. The common-mode rejection ratio is 5 / 0.05 = 100, or 40 dB. Divide the two expressions and RD cancels, leaving CMRR ≈ gmRtail. The lesson is in that formula: a better tail source, often a cascode, directly buys rejection.

With a perfectly matched pair and a differential output, the common-mode movement appears identically on both drains and cancels completely. In practice, mismatch between M1 and M2 or between the two loads turns some common-mode signal into a differential one, and that conversion, not the tail alone, usually sets the real CMRR. Matching is why differential pairs get careful common-centroid layout.

Inside op-amps and comparators

A pair with resistor loads is rarely used as is. The classic input stage replaces the resistors with a PMOS current-mirror load. The mirror copies M1's current change to the other side, so both halves of the signal add at one output. You get a single-ended output with the full gain gm(ro2 ∥ ro4), and the five-transistor circuit (pair, mirror, tail) is the first stage of the standard two-stage op-amp.

In a comparator, the same pair is a preamplifier ahead of a latch. Its gain makes small input differences large enough for the latch to resolve quickly, and it isolates the inputs from the latch's switching.

Practical limits to watch:

  • Input common-mode range: the tail source needs its own headroom, so the inputs cannot go too close to ground with an NMOS pair. Rail-to-rail inputs use NMOS and PMOS pairs in parallel.
  • Offset: threshold mismatch between M1 and M2 appears directly as an input offset voltage, so the pair is sized large for matching.
  • Linear range: the pair is linear only for input differences well below √2 VOV; larger overdrive extends the range but lowers gm per microampere.

Try it yourself

  1. Build the resistively loaded pair above in ngspice with sky130 devices and an ideal 100 µA tail. Sweep the differential input with .dc and plot both drain currents to see the steering and the point of full switching.
  2. Run an ac analysis with the inputs driven in antiphase, then in phase, and compute the ratio of the two gains.
  3. Replace the ideal tail with a single NMOS current source, repeat the in-phase run, and see how much the common-mode gain grows.
