Current mirrors: copying a current and why matching matters

Analog & mixed-signal Beginner 27 Nov 2026 5 min read By Ketuna

A current mirror copies one reference current to many places on a chip. Learn how the basic two-transistor mirror works, what its output resistance means, and how mismatch and channel-length modulation spoil the copy.

  2. Scaling the copy
  3. Output resistance and channel-length modulation

Analog circuits run on bias currents. An amplifier needs a few microamperes here, a comparator a few there, a charge pump some more. Generating each one from scratch would be wasteful and inaccurate, so chips make one good reference current and copy it everywhere with current mirrors. The mirror is probably the most repeated analog structure on any chip, and understanding where its copy goes wrong teaches you most of what matters about transistor matching.

How two transistors copy a current

The basic mirror uses two NMOS transistors, M1 and M2, with their sources at ground and their gates tied together. M1 is diode-connected: its gate is wired to its own drain. A reference current IREF is pushed into that node.

Here is what happens. The current has to flow through M1, so the gate-drain node rises until M1's VGS is exactly what it takes to carry IREF. Because the drain equals the gate, VDS = VGS, which is always larger than VGS − VTH, so M1 is guaranteed to be in saturation. The diode connection turns a current into a voltage automatically.

M2 sees the same VGS. If M2 is also in saturation and is identical to M1, the square-law equation gives it the same current. The mirror does not copy current directly. It copies a gate voltage, and relies on the second transistor to turn that voltage back into the same current.

Scaling the copy

In saturation, current is proportional to W/L. Making M2 four times wider than M1, with the same length, gives four times the current:

IOUT = IREF × (W/L)2 / (W/L)1

In layout you would build that 4× device as four copies of M1's unit transistor in parallel, not as one wide transistor. Identical units make the ratio an integer count of identical shapes, which matches much better than a ratio of drawn dimensions. For the same reason, ratios are set with width (more units), not length: a small error in printed length would change every unit in a different way.

One reference can feed many mirror outputs: a bank of M2 copies, each sinking its own current, all sharing one gate line.

Output resistance and channel-length modulation

An ideal current source delivers the same current whatever voltage sits across it. A real mirror does not. Because of channel-length modulation, the saturation current rises slowly with VDS, by a factor (1 + λVDS). The output resistance ro ≈ 1 / (λID) captures this: a higher ro means a flatter, better current source.

Here is the problem it causes. M1's VDS is fixed at its VGS. M2's VDS is whatever the load leaves it. If they differ, so do the currents:

IOUT / IREF = (1 + λVDS2) / (1 + λVDS1)

Worked example, with illustrative numbers: IREF = 20 µA, λ = 0.1 V−1, VGS = VDS1 = 0.7 V, and the load leaves VDS2 = 1.5 V. The ratio is 1.15 / 1.07 ≈ 1.075, so the "copy" is about 7.5 % too large. The output resistance is 1 / (0.1 × 20 µA) = 500 kΩ.

Two standard fixes follow from the formula. Use a longer channel: λ falls roughly in inverse proportion to L, so doubling L roughly halves the error and doubles ro. Or add a cascode: a second transistor stacked on M2 that holds M2's drain at a nearly constant voltage, which raises output resistance by roughly the intrinsic gain of the added device. The price of a cascode is headroom: the output now needs about one extra overdrive voltage before both devices stay saturated.

Mismatch: when the two transistors are not twins

Even with equal VDS, two transistors drawn identically are never quite identical. Random variations in doping and edge roughness give each a slightly different threshold voltage. A threshold difference ΔVTH shifts the overdrive of one device, and in saturation the current error is approximately:

ΔI / I ≈ 2 ΔVTH / VOV

Worked example, illustrative numbers: a pair with a threshold mismatch of 3 mV (one standard deviation). At VOV = 0.2 V the current error is 2 × 3 mV / 0.2 V = 3 %. At VOV = 0.4 V it falls to 1.5 %.

So mirrors match better at larger overdrive, because a fixed threshold error is a smaller fraction of a larger overdrive. That costs headroom, since the output must stay above VOV. Mismatch also falls with device area: the standard deviation of ΔVTH scales roughly as 1/√(WL), so quadrupling the area halves it. Matching is paid for in area and voltage, and you choose how.

Common mistakes

  • Letting the output fall out of saturation. Below VDS2 ≈ VOV, M2 enters triode and the current collapses. Always check the minimum output voltage.
  • Minimum-length mirror devices. Short devices have large λ and poor matching; analog mirrors usually use several times the minimum length.
  • Ratioing by length. Use the same L and parallel units.
  • Ignoring source wiring. A few ohms of extra wire resistance in one source shifts its effective VGS and therefore its current.

Try it yourself

  1. In ngspice with sky130 models, build a 1:1 NMOS mirror with IREF = 20 µA from a current source. Add a voltage source on M2's drain and run .dc from 0 to 1.8 V.
  2. Plot IOUT. Find where it flattens (saturation) and measure the slope there; its inverse is the output resistance.
  3. Double L for both devices (and W, to keep W/L) and repeat. Compare the slope and the minimum voltage, then predict the change with the formulas above before you look.
