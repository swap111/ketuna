Inside a PLL: phase detector, charge pump, loop filter and VCO

Analog & mixed-signal Intermediate 27 Nov 2026 6 min read By Ketuna

A phase-locked loop multiplies a slow, accurate crystal into a fast clock. Walk through what each block does, why the loop filter needs a resistor, and watch a simple model lock in Python.

A crystal oscillator gives an accurate, stable frequency, but only up to a few tens of megahertz. A processor wants hundreds of megahertz, a serial link gigahertz. The phase-locked loop (PLL) bridges the gap: it runs a fast, tunable oscillator and continuously steers it so that a divided-down copy stays in step with the crystal. Every block in the loop is simple on its own. The art is in how they work together, and that is what this article walks through.

The loop at a glance

A charge-pump PLL has five blocks in a ring:

  1. A phase-frequency detector (PFD) compares the reference clock with the feedback clock.
  2. A charge pump (CP) turns the PFD's decisions into packets of current.
  3. A loop filter turns those current packets into a smooth control voltage.
  4. A voltage-controlled oscillator (VCO) produces a frequency set by that voltage.
  5. A feedback divider divides the VCO output by N and returns it to the PFD.

When the loop is locked, the divided VCO clock has the same frequency and a fixed phase relative to the reference, so:

fVCO = N × fREF

With a 12 MHz crystal and N = 40, the VCO runs at 480 MHz. Change N and the output frequency changes in steps of fREF; that is an integer-N synthesiser.

Phase-frequency detector: two flip-flops and a gate

The usual PFD is two D flip-flops with their D inputs tied high, plus an AND gate. The reference clock clocks the first flip-flop, whose output is called UP; the feedback clock clocks the second, whose output is DOWN. When both outputs are high, the AND gate resets both.

Follow one cycle. If the reference edge arrives first, UP goes high and stays high until the feedback edge arrives, sets DOWN, and the AND resets both. The width of the UP pulse equals the time by which the reference led. If the feedback edge comes first, DOWN pulses instead. So the PFD outputs a pulse whose width is the phase error and whose identity (UP or DOWN) is its sign.

The "frequency" part matters too. If the VCO is far off frequency, one input produces more edges than the other, and the PFD keeps asserting the same output most of the time. A plain multiplier phase detector would average to zero in that case; the PFD instead pushes the loop steadily in the right direction, so the PLL pulls in from any starting frequency within the VCO's range.

Charge pump and loop filter: from pulses to a voltage

The charge pump is two switched current sources: UP connects a current ICP into the loop filter, DOWN connects an equal current out of it. Each reference cycle delivers a charge of ICP times the pulse width, so the charge is proportional to the phase error.

If the filter were just a capacitor, the control voltage would be the integral of phase error. But the VCO already integrates: phase is the integral of frequency. Two integrators in a loop give 180° of phase shift at all frequencies, so the loop would have zero phase margin and oscillate. The fix is a resistor in series with the capacitor. The resistor adds a voltage ICP × R during each pulse, a term proportional to phase error rather than integrated. In control terms it creates a zero that restores phase margin around the loop bandwidth.

A small capacitor, typically about a tenth of the main one, is added in parallel with the series R-C. Without it, every charge-pump pulse would produce a voltage step across R and jolt the VCO frequency once per reference cycle, producing spurs at the reference frequency in the output spectrum. The small capacitor smooths those steps.

The VCO and the divider

On chip the VCO is commonly a ring oscillator: an odd number of inverting stages in a loop, oscillating at f = 1/(2·n·td) for n stages of delay td. The control voltage sets the stage delay, for example by limiting each stage's current. Ring oscillators are small and tune widely, but they are noisier than LC oscillators, which use an on-chip inductor and capacitor and are used where low phase noise matters, such as radio synthesisers.

The VCO's tuning sensitivity KVCO, in hertz per volt, is a loop gain parameter as important as ICP. The divider is digital: a counter that toggles its output every N/2 input cycles, or a chain of prescalers for high frequencies.

Watching it lock

The model below updates the loop once per reference cycle. Each cycle it measures the phase error, delivers the corresponding charge to the filter, sets the VCO frequency from the control voltage, and advances the VCO phase. The values are illustrative, chosen for a loop bandwidth of a few hundred kilohertz, well below the 12 MHz reference.

# Phase-domain model of a charge-pump PLL, updated once per reference
# cycle. Illustrative values: 12 MHz reference, N = 40, 480 MHz target.
F_REF, N = 12e6, 40
T_REF = 1 / F_REF
F0, KVCO = 400e6, 200e6      # VCO: 400 MHz at 0 V, 200 MHz per volt
ICP = 50e-6                  # charge-pump current, A
R, C = 12.5e3, 50e-12        # loop filter: R in series with C

phase_vco = 0.0              # VCO phase, in VCO cycles
v_c = 0.0                    # voltage on the loop-filter capacitor
for n in range(1, 121):
    err = n - phase_vco / N             # phase error, reference cycles
    err = max(-1.0, min(1.0, err))      # a PFD saturates at one cycle
    charge = ICP * err * T_REF          # UP or DOWN pulse into the filter
    v_c += charge / C                   # integral path
    v_ctrl = v_c + ICP * R * err        # plus proportional path (R)
    f_vco = F0 + KVCO * v_ctrl
    phase_vco += f_vco * T_REF
    if n % 15 == 0:
        print(f"cycle {n:3d}: f_vco {f_vco/1e6:7.2f} MHz, "
              f"error {err:+.3f} cycles")

Starting from 400 MHz, the VCO overshoots to about 486 MHz by cycle 15, swings back below 480 MHz, and settles at 480.00 MHz with essentially zero phase error by about cycle 60, which is 5 µs at 12 MHz. Set R to zero and run it again: the loop oscillates, exactly as the two-integrator argument predicts.

The model is deliberately simple. It averages each pulse over a cycle, ignores the small filter capacitor and treats the VCO as perfectly linear. Real design uses a continuous-time linear model for bandwidth and phase margin, then a behavioural or transistor-level simulation.

Design choices and pitfalls

  • Loop bandwidth. Keep it well below the reference frequency, often a tenth or less, because the PFD only samples the phase once per reference cycle. Inside the bandwidth the loop follows the reference and suppresses VCO noise; outside it, VCO noise passes through.
  • Larger N multiplies noise. Reference and PFD noise appear at the output multiplied by N. A higher reference frequency, and so a smaller N, is usually better.
  • Charge-pump mismatch. If the UP and DOWN currents differ, the loop settles with a static phase offset that makes their charges cancel, and the resulting pulses each cycle cause reference spurs.
  • Lock detection. Firmware must not switch the system clock to the PLL until a lock-detect signal confirms the loop has settled.

Try it yourself

  1. Run the model above, then halve and double ICP and R and see how settling time and overshoot change.
  2. Write the two-flip-flop PFD in Verilog and simulate it with Icarus Verilog using two clocks of slightly different frequency; view UP and DOWN in GTKWave and confirm the pulse widths track the phase difference.
  3. In ngspice, build a three-stage current-starved ring oscillator with sky130 devices and plot its frequency against control voltage to find KVCO.
