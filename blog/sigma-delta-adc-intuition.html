Sigma-delta ADCs: trading speed for resolution with oversampling and noise shaping

Analog & mixed-signal Advanced 27 Nov 2026 5 min read By Ketuna

A one-bit quantizer inside a feedback loop, run far faster than the signal, plus a digital filter, gives high resolution at low bandwidth. See why noise shaping works, simulate it, and learn its limits.

In this article

  2. Feedback shapes the noise
  3. Checking it in simulation
  4. The decimation filter does half the work

  6. Try it yourself

How can a converter whose only analog decision is a single comparator deliver 20 or more bits? The sigma-delta (ΔΣ) ADC does it by refusing to resolve each sample accurately. It makes a crude one-bit decision millions of times a second, uses feedback to push the resulting error out of the band you care about, and lets a digital filter throw that error away. The analog precision requirements move into time and arithmetic, which CMOS does well. This article builds the intuition, checks it with a simulation, and covers what limits real designs.

Oversampling alone buys little

Quantization adds an error of roughly uniform distribution, with total power LSB2/12, spread evenly from DC to half the sampling rate. Sample at OSR times the Nyquist rate of your signal and the same noise power spreads over an OSR-times wider band. A digital low-pass filter then keeps only the signal band, removing a fraction (OSR − 1)/OSR of the noise.

The gain is 10·log10(OSR) dB: 3 dB, or half a bit, per doubling. Going from 1 bit to 16 bits this way would need an absurd OSR. Something more is needed.

Feedback shapes the noise

The trick is to put the quantizer inside a loop with an integrator.

The integrator accumulates the difference between the input and what the loop has output so far. Whenever the running error grows, the quantizer flips to correct it. For a constant input of 0.3 (on a ±1 scale), the output bitstream becomes a pattern of +1 and −1 values whose average is exactly 0.3. The loop does not care that each bit is wrong by a lot; it guarantees that the accumulated error stays bounded.

In the frequency domain, model the quantizer as an adder of error e. For the first-order loop in discrete time, the output is:

Y(z) = z−1X(z) + (1 − z−1)E(z)

The signal passes through with a delay. The error is multiplied by (1 − z−1), a high-pass filter with a zero at DC: the noise transfer function. Quantization noise is suppressed near DC and pushed towards half the sampling rate. That is noise shaping. A second integrator gives (1 − z−1)2, an even steeper high-pass. Theory for an L-th order loop predicts an in-band improvement of about (6L + 3) dB per doubling of OSR: 9 dB for first order and 15 dB for second, instead of 3.

Checking it in simulation

The script below runs first- and second-order one-bit modulators on a sine wave at half of full scale and measures in-band signal-to-quantization-noise ratio (SQNR) from an FFT:

import numpy as np

def modulate(x, order):
    """1-bit sigma-delta modulator, first or second order."""
    i1 = i2 = 0.0
    y = np.empty_like(x)
    for n, xn in enumerate(x):
        v = i2 if order == 2 else i1
        y[n] = 1.0 if v >= 0 else -1.0       # the one-bit quantizer
        i1 += xn - y[n]                      # first integrator
        if order == 2:
            i2 += i1 - y[n]                  # second integrator
    return y

def inband_sqnr(y, k_sig, osr):
    spec = np.abs(np.fft.rfft(y * np.hanning(len(y)))) ** 2
    band = len(y) // (2 * osr)               # bins up to fs / (2 * OSR)
    sig = spec[k_sig - 2:k_sig + 3].sum()    # Hann window spreads 3 bins
    noise = spec[1:band].sum() - sig
    return 10 * np.log10(sig / noise)

N, OSR, k = 2 ** 16, 64, 31                  # tone well inside the band
x = 0.5 * np.sin(2 * np.pi * k * np.arange(N) / N)
for order in (1, 2):
    y = modulate(x, order)
    print(f"order {order}: in-band SQNR {inband_sqnr(y, k, OSR):5.1f} dB")

Varying the OSR argument of inband_sqnr on the same bitstreams gives:

OSR First order Second order
32 39.0 dB 55.0 dB
64 46.3 dB 70.1 dB
128 54.5 dB 85.1 dB
256 62.6 dB 98.2 dB

The second-order loop gains about 15 dB per doubling, as predicted; the first-order loop gains about 8 dB, close to its predicted 9. At OSR 256 the second-order modulator delivers roughly 16 bits of SQNR from one comparator. The absolute values fall short of the textbook formula, because that formula treats the quantizer as a linear gain plus white noise, which a one-bit quantizer is not. Simulate rather than trust the formula.

The decimation filter does half the work

The modulator's output is a fast, one-bit stream full of high-frequency noise. The decimation filter low-pass filters it to the signal band and reduces the rate by OSR, producing multi-bit words. It must attenuate the shaped noise strongly, because anything left above the new Nyquist frequency folds back into the band during decimation. A common structure is a cascade of sinc (comb) filters, cheap because they need no multipliers, followed by sharper FIR stages at lower rates. A useful rule is that the sinc order should exceed the modulator order by one, so the filter's roll-off beats the noise's rise.

This is why sigma-delta converters are "slow": the output rate is the modulator clock divided by OSR, and the filter adds latency of many output samples. That latency is fine for audio, weighing, temperature and energy metering, and wrong for a fast control loop.

Where real designs struggle

  • Stability of high-order loops. Beyond second order, a one-bit loop can overload: integrator states grow without bound for large inputs. Designers limit the input range, scale the loop coefficients, and add reset logic.
  • Idle tones. First-order loops with DC inputs produce periodic patterns that appear as tones in the band. Higher order, dither, or multi-bit quantizers break them up.
  • The feedback DAC must be perfect. Its errors enter at the input, unshaped. A one-bit DAC has only two levels, so it is inherently linear, which is a major reason for using one bit. Multi-bit loops improve stability and SQNR but need DAC mismatch shaping.
  • Integrator leakage and finite op-amp gain move the noise-transfer zeros away from DC and let noise leak into the band.
  • Clock jitter matters greatly in continuous-time modulators, where the DAC pulse width directly sets how much charge is fed back.

Try it yourself

  1. Run the script with numpy, plot the spectrum of the bitstream on a log-frequency axis, and see the noise floor rise at 20 dB per decade (first order) and 40 dB per decade (second order).
  2. Feed a constant input such as 0.001 to the first-order loop and look for idle tones in the spectrum. Add a little random dither and compare.
  3. Write a first-order modulator and a simple counter-based sinc decimator in Verilog, simulate with Icarus Verilog or Verilator, and compare the decimated words with the Python model.
